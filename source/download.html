Good to know

Installation notes

What if the VK-172 is not detected?

Open Windows Device Manager, identify the receiver’s COM port, then select that port in GPS Time Sync and click Save.

Can I use another GPS receiver?

A compatible receiver that outputs supported NMEA sentences may work through manual COM-port selection. Automatic detection is specific to the VK-172 hardware signature.

Why must it run as administrator?

Changing the Windows system clock is a protected operation. Without administrator rights, GPS data can still be read, but a requested clock correction may fail.

What does the application log?

Optional NMEA logging helps diagnose receiver data. Time-change messages are recorded for synchronization troubleshooting.
