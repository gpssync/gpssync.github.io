Main Window

The main window shows GPS position, fix status, satellite status, current time, sync settings, and the log window.



AreaDescription
Latitude and LongitudeShows current GPS position when a valid fix is available.
Fix qualityShows GPS or DGPS quality information.
Fix modeShows whether the receiver has valid GPS data.
Satellites in useShows the number of satellites used for the current fix.
Satellites in viewShows visible satellites reported by the receiver.
Approximate elevationShows GPS elevation. This value can fluctuate with satellite movement.
Current TimeShows the GPS-derived time in the selected local or UTC mode.
LoggingShows incoming NMEA data and application messages.
