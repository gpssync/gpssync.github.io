GPS Time Sync

User Help








Version 1.20

GPS Time Sync is a Windows utility for synchronizing the computer clock from a GPS receiver.

Overview

GPS Time Sync reads NMEA time data from a GPS receiver and uses it to keep the Windows system clock accurate. The application was written for use with a VK-172 USB GPS dongle.

FeaturePurpose
GPS receiver detectionLooks for the VK-172 GPS dongle and selects the matching COM port when possible.
Manual COM setupAllows manual COM port selection when automatic detection is not available.
UTC or local timeCan set Windows time as UTC or local time.
Drift correctionUpdates the clock when the difference exceeds the configured drift threshold.
LoggingRecords GPS data and time-change messages for troubleshooting.
It should be noted that this application has to be run as administrator to allow it to change the system clock:





Quick Start

  1. Plug the VK-172 GPS dongle into the computer.
  2. Start GPS Time Sync.
  3. Confirm the selected COM port, or choose the correct port manually.
  4. Confirm the baud rate. The usual value is 9600.
  5. Select Set Local or Set UTC.
  6. Set the interval and drift threshold.
  7. Click Save.

Note: GPS reception may take a few moments after the receiver is connected.

GPS Receiver Setup

This is the GPS Time Sync screen:

GPS Time Sync is designed for a VK-172 USB GPS dongle. When the program starts, it attempts to detect the receiver and select the correct COM port.

If the receiver is detected

Confirm the selected COM port and baud rate, then click Save.

If the receiver is not detected

  1. Open Windows Device Manager.
  2. Find the COM port assigned to the GPS receiver.
  3. Select that COM port in GPS Time Sync.
  4. Click Save.

Synchronization Settings

SettingUse
COM PortThe serial port assigned to the GPS receiver.
Baud RateThe receiver speed. Use 9600 unless your device requires another value.
Interval (Seconds)How often GPS Time Sync compares the Windows clock to GPS time.
Drift >=The allowed difference, in seconds, before the clock is corrected.
Set UTCSets Windows system UTC from GPS UTC.
Set LocalSets Windows local time using GPS UTC converted through Windows time-zone rules.
Enable LoggingShows and records GPS/NMEA diagnostic data.

Important: Updating Windows time may require administrator rights.

Saving Settings

Click Save after changing the COM port, baud rate, sync interval, drift threshold, UTC/local mode, or logging option.

Save applies the selected values and attempts to reopen the GPS serial port using the current COM port and baud rate.

Hide to Tray

The application will start and automatically hide to tray.  You may also click Hide To Tray to keep GPS Time Sync running in the background and hidden after you have made changes.. The tray icon indicates that the program is still active.

Click the tray icon to restore the main window.

Logs

Logs help diagnose GPS receiver, COM port, and time synchronization problems. Logs are not really necessary unless you want to review the data periodically.  The log may be turned off without any adverse effects.

LogPurpose
Logging windowShows incoming GPS/NMEA lines and application status while the app is running.
GPSTimeChange.logRecords application startup, shutdown, settings changes, and time correction messages.
gps_sync.logMay be present in builds that write additional GPS synchronization diagnostics.

Logs are normally stored beside the executable.

Troubleshooting

VK-172 GPS dongle not detected

  • Unplug and reconnect the receiver.
  • Check Device Manager for the assigned COM port.
  • Select the port manually and click Save.

Cannot open COM port

  • Verify the selected COM port.
  • Close other programs that may be using the receiver.
  • Confirm the baud rate is correct.

System time does not update

  • Run GPS Time Sync as administrator.
  • Confirm that valid GPS time is being received.
  • Check the log for error messages.

Elevation changes often

This is normal. GPS elevation can fluctuate as satellite geometry changes.

Recommended Operating Practice

  • Use the same USB port for the GPS dongle when possible.
  • Verify the COM port after Windows updates or USB device changes.
  • Leave logging off during normal use unless troubleshooting.
  • Run as administrator when the app must update Windows system time.
  • Review logs after time synchronization problems.
